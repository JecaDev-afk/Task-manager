# Task Manager

A modern, responsive Task Management application built with React and TypeScript. This application features an interactive Kanban-style board allowing users to easily organize, prioritize, and track their tasks.

## Features

- **Kanban Board:** Organize tasks with intuitive drag-and-drop functionality across different stages (e.g., To Do, In Progress, Done).
- **Task Management:** Create, edit, and delete tasks with detailed information including dates and descriptions.
- **State Management:** Robust, centralized application state handling using Redux Toolkit.
- **Responsive Design:** Beautifully styled with SCSS, ensuring a seamless experience across all devices (desktop, tablet, and mobile).
- **Modern UI:** Clean, intuitive interface enhanced by smooth animations and Lucide React icons.

## Tech Stack

- **Frontend Framework:** React 19
- **Language:** TypeScript
- **Build Tool:** Vite
- **State Management:** Redux Toolkit & React-Redux
- **Drag and Drop:** @dnd-kit
- **Styling:** SCSS (Sass)
- **Routing:** React Router DOM
- **Icons:** Lucide React

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd task-manager
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

Start the development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

The application will be available at `http://localhost:5173/` by default.

### Building for Production

Create an optimized production build:

```bash
npm run build
```

To preview the built application locally:

```bash
npm run preview
```
